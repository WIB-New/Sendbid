Fonctionnalités

Tout ce dont vous avez besoin pour transférer en confiance

SendBID combine technologie fintech, biométrie, multi-devises et réseau d'agents pour une expérience unique.

Innovation

Enchère inverse 30 secondes

Notre algorithme exclusif diffuse votre demande à tous les agents disponibles dans le corridor concerné. Pendant 30 secondes, ils biddènt sur leurs frais. Le meilleur prix gagne.

  • WebSocket temps réel (latence < 200ms)
  • Visibilité totale sur tous les bids
  • Règles équitables : frais agent < frais client
  • Possibilité de « next round » si vous voulez relancer
Securite

Biométrie native + KYC 3 niveaux

Face ID, Touch ID, PIN, OTP : chaque transaction sensible est verrouillée. Le KYC est gradué selon le volume : plus vous envoyez, plus la validation est forte.

  • Authentification biométrique iOS/Android native
  • KYC Tier 1 (basique), 2 (ID), 3 (justificatifs corp.)
  • Chiffrement E2E des données sensibles
  • Audit logs complets et réconciliation automatique
Paiements

Stripe + PayPal + Mobile Money

Rechargez votre wallet FlooMoney depuis la méthode de votre choix. 100% in-app grâce à notre WebBrowser embarqué — jamais de redirection externe.

  • Stripe (carte bancaire mondiale)
  • PayPal (compte ou carte)
  • Mobile Money : MTN, Orange, Wave, Moov
  • Wallet multi-devises EUR / USD / XAF / XOF
International

250+ pays, 7 langues, RTL inclus

SendBID est disponible en français, anglais, espagnol, allemand, italien, portugais et arabe (avec support RTL natif). Le mode sombre est inclus partout.

  • i18n complet sur toute l'app
  • Support RTL pour l'arabe natif
  • Dark mode global synchronisé OS
  • Conversion multi-devises temps réel
